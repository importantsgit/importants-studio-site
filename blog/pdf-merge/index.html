PDF 합치기와 PDF 용량 줄이기 아이폰 활용법

관공서, 채용 사이트, 학교 등에 서류를 제출할 때 파일 개수나 용량 제한(예: 10MB 이하)이 있어 곤란한 경우가 있습니다. 여러 장의 스캔 문서나 사진을 하나의 PDF로 합쳐야 하거나, 용량이 커서 업로드가 안 될 때 상황에 맞는 방법을 선택하면 됩니다.

제출 전 확인해야 할 사항

파일을 작업하기 전에 반드시 제출처의 규칙을 먼저 확인해야 합니다. 파일 개수, 용량 제한, 허용되는 파일 형식(PDF만 가능한지 여부)을 확인한 뒤 작업을 시작하는 것이 효율적입니다.

작업 순서는 다음과 같습니다.

  1. 제출처의 파일 개수, 용량, 형식 제한을 확인합니다.
  2. 페이지 순서, 회전 상태, 불필요한 페이지를 정리합니다.
  3. 파일을 합칩니다.
  4. 합친 파일의 용량이 기준을 초과하면 용량을 줄입니다.
  5. 마지막으로 파일을 열어 페이지 수, 순서, 글자 선명도를 확인합니다.

아이폰에서 PDF 합치기 방법

아이폰을 사용 중이라면 별도의 도구 없이 기본 앱만으로도 사진 PDF 합치기가 가능합니다.

아이폰 기본 파일 앱 활용

아이폰의 ‘파일’ 앱을 이용하면 여러 개의 PDF나 사진을 하나로 묶을 수 있습니다.

  1. 파일 앱에서 합칠 PDF나 사진을 여러 개 선택합니다.
  2. 하단의 ’…(더 보기)’ 아이콘을 누릅니다.
  3. ‘PDF 생성’을 누르면 선택한 파일들이 하나의 PDF로 합쳐집니다. 이때 파일 이름 순서나 선택한 순서에 따라 페이지 순서가 결정되므로 미리 확인이 필요합니다. 다만, 파일 앱 자체에는 용량을 줄이는 기능은 없습니다.

웹사이트 이용하기 (iLovePDF 등)

브라우저를 통해 접속하는 웹사이트 방식은 PC와 모바일 모두에서 유용합니다.

  1. 브라우저에서 PDF 편집 사이트에 접속합니다.
  2. 파일을 업로드하여 합치기 또는 용량 줄이기를 진행합니다. 일부 사이트는 무료 사용 범위가 정해져 있으며, 더 많은 기능을 쓰려면 월 구독(예: iLovePDF 월 6,500~7,000원, 연 55,000원 — 앱스토어 표기 기준)이 필요할 수 있습니다. 특히 계약서나 신분증처럼 민감한 서류를 올릴 때는 보안을 고려하여 사이트 서버에 파일을 업로드해도 되는지 판단해야 합니다.

기기 전용 앱 활용

인터넷 연결 없이 작업하려면 아이폰 안에서 구동되는 전용 앱을 사용하는 것이 좋습니다. 앱을 선택할 때는 다음 사항을 확인해야 합니다.

  • 합친 결과물에 워터마크가 붙는지 여부
  • 저장 횟수 제한이 있는지 여부
  • 무료 체험 후 자동 결제로 전환되는 구독형 모델인지 여부 (사용자 리뷰를 통해 확인 권장)

PDF 용량 줄이기 원리와 주의점

스캔한 문서나 사진으로 만든 PDF는 페이지 하나하나가 이미지 형태라 용량이 큽니다. 용량 줄이기는 대개 이미지의 해상도와 품질을 낮추어 다시 저장하는 방식으로 작동합니다.

구분특징 및 방식주의사항
스캔/사진 PDF페이지가 이미지로 구성되어 용량이 큼해상도를 낮추면 글자가 흐려질 수 있음
문서형 PDF글자 데이터와 이미지가 혼합됨이미지만 줄여야 글자 품질을 유지하기 쉬움

용량을 줄일 때는 제출처에서 요구하는 목표 용량(예: 2MB 이하)을 기준으로 작업하는 것이 편리합니다. 많이 압축할수록 글자가 흐려질 수 있으므로, 작업을 마친 뒤에는 반드시 파일을 확대하여 글자가 선명하게 읽히는지 확인해야 합니다. 만약 용량을 아무리 줄여도 목표치에 미치지 못한다면 페이지를 나누어 여러 파일로 제출하거나, 해상도가 낮은 스캔본을 다시 만드는 방법을 고려해야 합니다.
