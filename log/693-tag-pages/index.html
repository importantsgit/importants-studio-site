태그 수를 따로 세지 않았습니다

블로그 여섯 개의 공개 글을 합치면 232편입니다. 태그 페이지를 세어 보니 693개였습니다. 글보다 태그 페이지가 3배 많았습니다.

693개 가운데 563개에는 글이 한 편만 달려 있었습니다. 블로그별 비율도 78퍼센트에서 89퍼센트 사이였습니다. 여섯 개가 비슷한 모양으로 늘어나 있었습니다.

글이 한 편뿐인 태그 페이지에는 그 글의 요약문만 들어가고, 요약문 길이는 270자에서 500자였으며, 같은 글에 여러 태그를 붙이면 서로 다른 태그 주소에서 같은 요약문이 반복됩니다. 한 블로그에서는 태그 페이지 세 개의 본문이 완전히 같았고, 다른 블로그에서는 두 개가 같았습니다.

태그를 붙일 때는 글을 찾기 쉽게 해 둔다고 생각했습니다. 태그 하나가 별도 페이지가 된다는 점은 알고 있었지만, 그 페이지 수를 글 수와 함께 세지는 않았습니다. 232편의 글 뒤에 693개의 주소가 생긴 상태였습니다.

크롤러가 들어갈 길도 열려 있었습니다

태그 페이지는 전부 검색 허용 상태였습니다. robots.txt도 아무것도 막지 않았습니다. 모든 글 하단에 태그 링크가 있으니 크롤러는 글을 읽은 뒤 태그 페이지로 들어갈 수 있습니다.

아직 색인은 안 됐습니다. 태그 페이지 네 개를 검사했는데 모두 "구글이 모르는 URL"로 나왔으며(검사한 네 개 기준입니다), 검색 결과에는 없지만, 사람이 사이트를 눌러 보면 태그 링크를 따라 이 페이지들을 마주칠 수 있습니다.

이 페이지들이 검색에서 데려온 노출도 확인했습니다. 28일간 전체 노출은 942회였고, 태그와 카테고리 페이지 몫은 3회였습니다. 태그와 카테고리 페이지를 따로 나눠 보지는 못했지만, 둘을 합쳐도 3회였습니다.

테마가 페이지를 만들고 있었습니다

애드센스 안내에는 비슷하거나 중복된 페이지가 많으면 합치거나 내용을 늘리라는 대목이 있고, 태그 페이지는 테마가 기본으로 만들어 주는 페이지라서, 직접 만든 기억조차 없었습니다.

글이 한 편인 태그 페이지 563개에는 270자에서 500자짜리 요약문이 전부이고, 같은 글이 여러 태그에 걸리면 그 요약문도 여러 주소에 그대로 들어갑니다. 세 개의 본문이 같았던 블로그와 두 개가 같았던 블로그는 이미 확인했습니다.

내가 쓴 글만 세고 있었고, 사이트가 자동으로 만들어 내는 페이지는 세지 않았습니다. 검색에서 얻는 게 942회 중 3회인데 위험은 693장어치입니다.
