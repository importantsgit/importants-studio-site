뽑기 한입 개인정보처리방침

뽑기 한입(Lucky Bite)은 이용자의 개인정보를 최소한으로 처리하며, 관련 법령과 App Store 정책을 준수합니다. 아래는 개인정보 처리에 관한 안내입니다.

1. 수집하는 정보

앱에서 직접 수집·저장하는 정보

  • 회원가입·로그인 없이 사용 가능합니다.
  • 운영 서버가 없으며, 앱이 개발자에게 개인정보를 전송하지 않습니다.
  • 기기에만 저장: 사용자가 입력한 참가자 이름·프리셋(모임 명단), 사용자가 사진첩에서 고른 참가자 사진, 게임 기록(당첨·순위), 스킬·방장 모드·공정 모드 등 설정. 앱 삭제 시 함께 삭제되며, 개발자는 접근할 수 없습니다.

사진·카메라·마이크·음성 인식·AI

  • 사진: 참가자 사진을 고를 때만 사용자가 선택한 사진에 접근하며, 기기 안에만 저장합니다.
  • 카메라: 카메라 게임(얼굴 룰렛·웃으면 탈락·눈싸움)에서만 사용합니다. 얼굴 위치·표정 정보와 결과 카드 얼굴 사진의 처리는 2. 얼굴 데이터에 따릅니다.
  • 마이크·음성 인식: AI 법정에서 변론을 말로 입력할 때만 사용합니다. 기기에서 음성 인식을 지원하면 기기 안에서 글자로 바꾸며, 녹음 파일을 저장하거나 개발자에게 전송하지 않습니다. 기기가 지원하지 않는 경우 Apple의 음성 인식 서비스가 처리할 수 있으며, 이는 Apple 개인정보처리방침을 따릅니다.
  • AI 게임: AI 밸런스 게임, AI 마음대로, AI 법정, 라이어 게임의 AI 제시어 기능은 Apple Intelligence를 통해 처리됩니다. iOS 27 이상 지원 기기에서 답변 생성에 필요한 텍스트(AI 법정의 변론, 상황, 참가자 이름 등)는 Apple의 Private Cloud Compute 서버로 전송되어 처리되거나, 서버 사용이 불가능할 경우 기기 내 모델(Foundation Models)을 통해 처리됩니다. 모든 서버 처리는 Apple의 개인정보처리방침을 따르며, 해당 내용은 개발자나 Apple 이외의 다른 AI 서비스로 전송되지 않습니다.

제3자 SDK를 통한 정보 수집

  • Google AdMob(광고): 광고 식별자(IDFA, 추적 동의 시), IP 주소 기반 대략적 위치, 광고 노출·클릭 정보, 기기 정보.
    목적: 광고 게재, 맞춤 광고, 광고 성과 측정.
  • Google Analytics for Firebase(분석): 앱 사용 이벤트(실행, 화면, 버튼 등), 기기 모델, OS 버전, 언어, 국가, 앱 인스턴스 식별자, 인앱 구매 이벤트.
    목적: 서비스 이용 통계, 기능 개선.
  • Firebase Crashlytics(오류 수집): 충돌 로그, 기기 상태, 앱 버전, 설치 식별자.
    목적: 오류 분석, 안정성 개선.

SDK가 수집한 정보는 Google 서버로 전송되며, Google 개인정보처리방침에 따라 처리됩니다.

2. 얼굴 데이터 (TrueDepth 카메라 / ARKit)

  • 사용처: '눈싸움' 및 '표정 분석' 기능이 활성화된 '웃으면 탈락' 게임에서 사용됩니다. 이 두 게임은 Face ID 기기의 TrueDepth 카메라를 활용한 ARKit 얼굴 트래킹 기술을 사용합니다. ('얼굴 룰렛' 및 '표정 분석' 기능이 꺼진 상태의 '웃으면 탈락'은 Apple Vision 얼굴 감지 기능이 적용된 일반 카메라를 사용하며, TrueDepth 카메라는 사용하지 않습니다.)
  • 수집 항목: (a) 화면상 각 얼굴의 위치 및 (b) ARKit에서 추출한 표정 값(눈 깜빡임, 미소, 눈썹, 볼, 코, 턱에 대한 0에서 1 사이의 수치)만을 수집합니다. 뽑기 한입은 깊이 맵(depth maps)이나 3D 얼굴 메시를 사용하지 않으며, 얼굴 템플릿을 생성하거나 개인을 식별하지 않습니다.
  • 목적: 화면에서 게임을 실행하기 위한 목적으로만 사용됩니다. 즉, 눈 깜빡임 횟수 계산, 미소 감지, 표정 점수 표시, 각 플레이어의 얼굴 옆에 마커를 표시하는 용도로만 사용됩니다.
  • 저장 및 보유: 데이터는 기기 메모리 내에서 실시간으로만 처리됩니다. 기기 저장소에는 절대 기록되지 않으며, 얼굴이 카메라 시야를 벗어나거나 게임 화면을 닫으면 즉시 폐기됩니다.
  • 공유: 얼굴 데이터는 개발자, 서버 또는 Google AdMob 및 Firebase를 포함한 제3자에게 전송되지 않습니다. 또한 광고, 분석 또는 개인 식별 용도로도 사용되지 않습니다. 분석 도구는 플레이어 수와 게임 모드 정보만 수신합니다.
  • 결과 카드 내 얼굴 사진: 카메라 게임이 시작되면, 뽑기 한입은 결과 카드에 표시하기 위해 일반 카메라 이미지에서 각 플레이어의 얼굴 영역을 잘라냅니다. 이 사진은 메모리에만 유지되며 게임 화면을 닫으면 삭제됩니다. 사용자가 공유 버튼을 누르고 전송 위치를 직접 선택하는 경우에만 기기 외부로 나갑니다. 결과 카드에는 표정 값이 포함되지 않습니다.
  • 삭제: 데이터가 저장되지 않으므로 게임 화면을 닫는 것만으로 모든 데이터가 삭제됩니다. 카메라 접근 권한은 iPhone 설정 > 뽑기 한입 > 카메라에서 언제든지 끌 수 있습니다.

Face Data (TrueDepth camera / ARKit) — English

  • Where it is used: "Staring Contest", and "Try Not to Laugh" when "Expression Analysis" is turned on. These two use ARKit face tracking with the TrueDepth camera on Face ID devices. ("Face Roulette" and "Try Not to Laugh" with Expression Analysis off use the regular camera with Apple Vision face detection and do not use the TrueDepth camera.)
  • What is collected: only (a) the position of each face on the screen and (b) facial expression values from ARKit (numbers from 0 to 1 for eye blinks, smile, eyebrows, cheeks, nose and jaw). The app does not use depth maps or the 3D face mesh, does not create face templates, and does not identify who a person is.
  • Purpose: only to run the game on screen: counting eye blinks, detecting smiles, showing expression scores, and showing each player's marker next to their face.
  • Storage and retention: the data is processed in real time in the device's memory only. It is never written to device storage. It is discarded when a face leaves the camera view or when the game screen is closed.
  • Sharing: face data is not sent to the developer, to any server, or to any third party, including Google AdMob and Firebase. It is not used for advertising, analytics, or identifying individuals. The analytics tool only receives the number of players and the game mode.
  • Face photo on the result card: when a camera game starts, the app cuts each player's face out of the regular camera image to show it on the result card. This photo is kept in memory only and is deleted when the game screen is closed. It leaves the device only if the user taps the Share button and chooses where to send it. The result card does not contain expression values.
  • Deletion: since nothing is stored, closing the game screen deletes everything. Camera access can be turned off anytime in iPhone Settings > Lucky Bite > Camera.

3. 수집 및 이용 목적

  • 앱 내 저장 정보: 뽑기 게임 제공, 참가자 명단·게임 기록 관리, 사용자 설정 유지.
  • 제3자 SDK: 광고 제공 및 성과 측정, 서비스 이용 통계, 앱 오류 분석 및 개선.

4. 제3자 제공 및 처리위탁

  • 앱은 별도의 개인정보를 제3자에게 제공하거나 처리위탁하지 않습니다.
  • 제3자 SDK(Google AdMob, Analytics, Crashlytics)에서 수집된 정보는 Google이 자체 서버에서 처리하며, Google 정책을 따릅니다.

5. 보유 및 파기

  • 앱 내 저장 정보는 기기에서만 보관되며, 앱 삭제 시 모두 삭제됩니다.
  • 제3자 SDK가 수집한 정보의 보유 기간은 Google 정책에 따릅니다.

6. 결제

  • 모든 결제는 Apple 인앱 결제로 처리되며, 개발자는 카드번호 등 결제 정보를 수집·보관하지 않습니다.
  • 구매 복원은 Apple 영수증으로 확인합니다.

7. 알림

  • 앱은 알림을 보내지 않습니다.

8. 이용자의 권리와 선택

  • 기기 설정 > 개인정보 보호 > 추적에서 광고 추적 허용을 철회할 수 있습니다.
  • 설정 > 개인정보 보호 > Apple 광고에서 맞춤 광고를 제한할 수 있습니다.
  • 앱 삭제로 기기 내 저장된 모든 정보가 삭제됩니다.
  • Google 광고 설정에서 맞춤 광고를 해제할 수 있습니다.

9. 아동의 개인정보

  • 앱은 아동을 대상으로 하지 않으며, 14세 미만 아동의 개인정보를 고의로 수집하지 않습니다.

10. 방침의 변경

  • 개인정보처리방침이 변경될 경우 이 페이지에 게시합니다.
