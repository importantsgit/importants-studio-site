Opus 5.5 가격표에서 캐시 읽기 단가를 놓쳤던 기록

2026년 10월 15일Importants Studio

이 저장소의 자동화는 지시문과 규칙, 예시 글을 앞에 붙인 뒤 같은 모델을 반복 호출합니다. 그래서 모델을 바꿀 때 입력과 출력 단가만 옮겨 적으면 실제 호출 흐름에서 계속 발생하는 캐시 읽기 비용을 빼먹게 됩니다.

앞선 기록에서는 Sonnet 5와 5.5, Haiku 5.5를 봤습니다. 이번에는 2026-10-15에 공식 가격 페이지를 직접 열고 Opus 5.5와 Opus 5를 같은 줄에 놓았습니다. 처음에는 입력 칸만 읽었습니다. 거기서 한 번 멈췄습니다.

먼저 결론부터

  • Opus 5.5의 기본 입력은 MTok당 $4, 출력은 $20이며, Opus 5는 각각 $5와 $25입니다.
  • 입력과 출력만 비교하면 Opus 5.5가 Opus 5보다 20% 낮게 보입니다.
  • 캐시 읽기는 Opus 5.5가 $0.20, Opus 5가 $0.50입니다. 이 칸에서는 60% 차이가 납니다.
  • Opus 5.5는 캐시 읽기와 갱신에 기본 입력 단가의 0.05배를 쓰고, Opus 5는 표준 0.1배를 씁니다.
  • 가격표 아래에는 Claude 4.7 이후 모델의 새 토크나이저 문구도 있었지만, Opus 5와 5.5가 실제로 어느 토크나이저를 쓰는지는 페이지에서 따로 확인하지 못했습니다.

입력 칸만 읽었을 때는 20% 차이였습니다

공식 가격표의 Opus 줄을 먼저 읽으면 기본 입력과 출력 단가가 바로 보입니다. Opus 5.5는 기본 입력 $4, 출력 $20이고 Opus 5는 기본 입력 $5, 출력 $25였습니다.

항목Opus 5.5Opus 5
기본 입력$4 / MTok$5 / MTok
출력$20 / MTok$25 / MTok

이 두 칸만 놓고 보면 비교는 단순합니다. 입력 $4와 $5, 출력 $20과 $25의 차이는 모두 20%입니다. 모델 단가가 내려갔다는 판단도 여기까지는 자연스럽게 이어집니다.

그런데 이 저장소에서는 입력이 한 번만 들어가지 않습니다. 앞에 붙는 지시문과 규칙, 예시 글이 반복 호출마다 다시 관여하므로 가격표의 다음 칸을 보지 않고 넘길 수 없었습니다.

캐시 읽기 칸에서 차이가 커졌습니다

표에는 기본 입력과 출력 사이에 캐시 쓰기와 캐시 읽기 항목이 있습니다. Opus 5.5의 가격은 5분 캐시 쓰기 $5, 1시간 캐시 쓰기 $8, 캐시 읽기 $0.20이었습니다. Opus 5는 같은 순서로 $6.25, $10, $0.50까지.

항목Opus 5.5Opus 5
5분 캐시 쓰기$5 / MTok$6.25 / MTok
1시간 캐시 쓰기$8 / MTok$10 / MTok
캐시 읽기$0.20 / MTok$0.50 / MTok

입력 단가에서는 20% 낮아진 정도로 읽혔는데, 캐시 읽기는 $0.20과 $0.50입니다. 60% 차이가 납니다.

처음에 입력 칸만 먼저 읽었던 탓에 이 차이는 표를 다시 내려가서야 보였습니다. 반복 입력이 있는 자동화에서는 기본 입력 단가보다 캐시 읽기 단가가 더 오래 남는다는 뜻이었습니다. 가격표의 한 줄을 본 것이 아니라 호출 흐름에 걸친 칸을 같이 읽어야 했던 이유입니다.

표 아래 각주에 0.05배가 있었습니다

캐시 읽기 $0.20이라는 숫자만 보면 왜 Opus 5.5의 값이 이렇게 달라졌는지 표 안에서는 알 수 없었습니다. 그럼 이유는 어디에 있었을까요? 표 아래 각주에 따로 적혀 있었습니다.

Opus 5.5와 Sonnet 5.5의 캐시 읽기와 갱신은 기본 입력 단가의 0.05배입니다. 나머지 모델은 표준 0.1배를 쓴다고 적혀 있었습니다.

계산도 숫자와 맞았습니다. Opus 5.5는 기본 입력 $4의 0.05배가 $0.20이고, Opus 5는 기본 입력 $5의 0.1배가 $0.50입니다.

같은 표에서 Opus 4.8, 4.7, 4.6, 4.5도 기본 입력 $5, 출력 $25, 캐시 읽기 $0.50으로 적혀 있었습니다. Opus 5.5의 캐시 읽기 값은 입력과 출력만 낮아진 결과가 아니라, 캐시 읽기 비율 자체가 달라진 결과였습니다.

토크나이저 문구는 가격표 아래에 있었습니다

가격표를 읽고 내려가면 Claude 4.7 이후 모델은 새 토크나이저를 쓴다는 문구가 나옵니다. 같은 텍스트에서도 토큰이 약 30% 더 나올 수 있고, 정확한 증가폭은 내용과 작업 형태에 따라 다르다고 되어 있었습니다.

단가가 낮아졌다고 해서 같은 글의 비용이 바로 같은 비율로 낮아진다고 적을 수 없었던 이유가 여기 있었습니다. MTok당 가격과 실제 토큰 수는 다른 줄에서 결정됩니다.

다만 이 페이지는 Opus 5와 Opus 5.5가 어느 토크나이저를 쓰는지 따로 적지 않았습니다. “4.7 이후”라는 문구에 두 모델이 모두 해당하는지도 직접 토큰을 세어 보지 않아 확인하지 못했습니다. 그래서 이번 기록에는 토크나이저 차이에 따른 비용 계산을 넣지 않았습니다.

이번 가격표에서 남은 비교값은 $4와 $5, $20과 $25만이 아니었습니다. 반복 호출의 앞부분을 캐시로 읽는 흐름에서는 $0.20과 $0.50, 그리고 0.05배와 0.1배가 함께 남았습니다.
