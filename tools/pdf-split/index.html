PDF 나누기

원하는 페이지를 추출하여 새 PDF로 저장합니다

공유된 결과

    How to use

    1. 1PDF 파일을 선택합니다
    2. 2원하는 쪽 범위를 입력하거나 모든 쪽을 각각 나눕니다
    3. 3새 PDF 파일로 저장합니다

    FAQ

    파일이 서버에 저장되나요?

    파일은 서버로 올리지 않고 브라우저 안에서만 처리합니다.

    특정 범위만 뽑을 수 있나요?

    1-3, 5와 같이 쪽 범위를 적으면 해당 쪽만 새 PDF로 저장합니다.

    파일을 한 장씩 나누는 것도 가능한가요?

    모든 쪽을 한 쪽씩 따로 나눠 저장할 수 있습니다.
