구슬 룰렛

구슬 레이스로 결정하는 재미있는 룰렛

공유된 결과

    How to use

    1. 1이름을 한 줄에 하나씩 입력합니다. 이름*3처럼 입력하면 구슬이 여러 개 생성됩니다.
    2. 2코스와 당첨 규칙을 선택하고 스킬 기능을 켭니다.
    3. 3굴리기 버튼을 눌러 경주를 시작합니다.

    FAQ

    이름을 입력할 때 규칙이 있나요?

    이름을 한 줄에 하나씩 적거나 쉼표로 구분합니다. 이름*3처럼 쓰면 해당 이름의 구슬이 여러 개 생성됩니다.

    스킬 기능은 어떻게 작동하나요?

    스킬을 켜면 구슬마다 무작위로 스킬이 부여되어 경주 중 한 번 발동합니다. 스킬은 굴릴 때마다 다시 정해집니다.

    입력한 이름이 저장되나요?

    이름은 서버로 보내지 않고 브라우저 안에서만 처리됩니다.

    결과 확인은 어떻게 하나요?

    경주가 끝나면 전체 순위가 표시되며 결과를 복사할 수 있습니다.
