양력 음력 변환

양력과 음력 날짜를 서로 변환합니다

공유된 결과

    How to use

    1. 1양력 → 음력 또는 음력 → 양력을 선택합니다
    2. 2년, 월, 일을 입력합니다 (음력 선택 시 윤달 체크 가능)
    3. 3입력과 동시에 변환 결과와 올해·내년 날짜를 확인합니다

    FAQ

    어느 범위의 날짜까지 변환할 수 있나요?

    1000년부터 2050년까지 변환할 수 있습니다.

    계산 데이터는 무엇을 기준으로 하나요?

    한국천문연구원 기준 데이터를 사용하는 라이브러리로 계산합니다.

    변환을 위해 버튼을 눌러야 하나요?

    날짜를 입력하는 동안 바로 결과가 나타납니다.

    2027 설날 연휴 →2027 추석 연휴 →2027년 공휴일 →
