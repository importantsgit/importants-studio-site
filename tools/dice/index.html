주사위 굴리기

참가자 명단으로 1등을 정하는 주사위 도구

공유된 결과

    How to use

    1. 1참가자 명단이 자동으로 입력되어 있어요
    2. 2주사위 굴리기를 누르면 모두의 주사위가 굴러가요
    3. 3가장 큰 숫자가 나온 사람이 1등이 돼요
    4. 4동점자가 있으면 동점자끼리 다시 굴려요

    게임이 끝나면 전체 순위가 표시돼요

    FAQ

    설치나 가입이 필요한가요?

    설치나 회원가입 없이 브라우저에서 바로 사용합니다.

    명단은 어디에 저장되나요?

    입력한 명단은 이 브라우저에만 저장됩니다.

    동점자가 나오면 어떻게 하나요?

    1등이 동점이면 동점자만 다시 굴립니다.
