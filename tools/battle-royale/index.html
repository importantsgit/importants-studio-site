이름 배틀로얄

이름 입력 후 배틀로얄로 당첨자 정하기

공유된 결과

    How to use

    1. 1이름을 입력하고 끝까지 살아남거나 가장 먼저 쓰러지는 규칙을 고릅니다
    2. 2전투 시작 버튼을 누르면 무기를 든 공들이 원형 경기장에서 자동으로 싸웁니다
    3. 3순위와 무기, 처치 수가 포함된 결과를 확인하고 복사합니다

    FAQ

    입력한 이름이 저장되나요?

    이름은 서버로 보내지 않고 브라우저 안에서만 처리됩니다.

    무기 성능은 어떻게 결정되나요?

    검, 단검, 창, 망치, 활 5개 무기를 매 판 무작위로 받으며 수천 판의 시험으로 승률을 맞췄습니다.

    전투는 언제 끝나나요?

    15초 후 경기장이 줄어들고 60초 후에는 체력이 줄어 반드시 끝납니다.
