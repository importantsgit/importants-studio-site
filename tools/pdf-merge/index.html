공유된 결과

    How to use

    1. 1합칠 PDF 파일들을 선택합니다
    2. 2파일별 쪽수를 확인하고 순서를 바꿉니다
    3. 3합치기 버튼을 눌러 하나의 파일로 만듭니다

    FAQ

    파일을 서버에 저장하나요?

    파일은 서버로 올리지 않고 브라우저 안에서만 처리합니다.

    회원가입이 필요한가요?

    설치나 회원가입 없이 브라우저에서 바로 사용합니다.

    암호가 걸린 파일도 가능한가요?

    암호가 걸린 PDF는 합칠 수 없습니다.
