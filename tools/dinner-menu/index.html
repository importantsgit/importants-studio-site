저녁 메뉴 추천

메뉴 종류를 골라 돌림판으로 저녁 메뉴 결정

공유된 결과

    How to use

    1. 1원하는 음식 종류를 선택하거나 메뉴를 직접 추가합니다
    2. 2메뉴를 삭제하거나 직접 입력하여 목록을 구성합니다
    3. 3돌림판을 돌려 나온 메뉴로 저녁 식사를 결정합니다

    FAQ

    회원가입이 필요한가요?

    회원가입 없이 브라우저에서 바로 사용합니다.

    메뉴를 마음대로 바꿀 수 있나요?

    메뉴를 직접 추가하거나 지울 수 있습니다.

    어떤 종류의 음식을 넣을 수 있나요?

    한식, 중식, 일식, 양식, 분식, 고기, 야식 등 종류를 골라 올릴 수 있습니다.

    뽑기 한입순서를 정할 때 고민을 끝내요모임의 모든 결정과 재미를 한 곳에서 해결해요
