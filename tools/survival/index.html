이름 서바이벌

이름 입력으로 정하는 자동 서바이벌 벌칙 정하기

공유된 결과

    How to use

    1. 1이름을 최대 12명까지 입력하고 탈락 방식과 걸 내용을 적습니다
    2. 2시작 버튼을 누르면 0.9초마다 자동으로 사건이 발생합니다
    3. 3탈락 순서와 최종 생존자가 결정되면 결과를 복사합니다

    FAQ

    입력한 이름이 서버에 저장되나요?

    이름은 서버로 보내지 않고 브라우저 안에서만 처리됩니다.

    능력치는 어떻게 결정되나요?

    공격, 방어, 회피, 운 능력치 총합 20이 시작할 때마다 새로 정해집니다.

    순위는 어떻게 결정되나요?

    가장 먼저 탈락한 사람과 끝까지 살아남은 사람이 정해지며 탈락 순서의 역순이 순위입니다.

    뽑기 한입순서를 정할 때 고민을 끝내요모임의 모든 결정과 재미를 한 곳에서 해결해요
